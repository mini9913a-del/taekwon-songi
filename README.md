# 태권송이의 대모험

태권도복을 입은 송이가 자동으로 달리며 점프·이단 점프·슬라이드·발차기로 10개 스테이지를 통과해 검은띠에 도전하는 웹 러닝 게임입니다.

## 조작

| 동작 | 모바일 | PC |
|---|---|---|
| 점프 | 탭 | Space / ↑ |
| 이단 점프 | 공중에서 한 번 더 탭 | 공중에서 Space |
| 슬라이드 | 아래로 쓸고 유지 | ↓ 누르고 있기 |
| 발차기 | 오른쪽으로 쓸기 | → |
| 일시정지 | – | P |

## 구성

- 스테이지 1~5: 점프·이단 점프·슬라이드
- 스테이지 6~10: 날아오는 송판 추가 (발차기로 격파)
- 목숨 1개, 실패 시 해당 스테이지부터 재도전
- 흰띠 → 노란띠 → 주황띠 → 초록띠 → 파란띠 → 보라띠 → 밤띠 → 빨간띠 → 품띠 → 검은띠
