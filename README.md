# 태권송이의 대모험

태권도복을 입은 송이가 자동으로 달리며 점프·이단 점프·슬라이드·발차기로 100개 스테이지를 통과해 검은띠에 도전하는 웹 러닝 게임입니다.

## 조작

| 동작 | 모바일 | PC |
|---|---|---|
| 점프 | 탭 | Space / ↑ |
| 이단 점프 | 공중에서 한 번 더 탭 | 공중에서 Space |
| 슬라이드 | 아래로 쓸고 유지 | ↓ 누르고 있기 |
| 발차기 | 오른쪽으로 쓸기 | → |
| 뒤로 피하기 | 왼쪽으로 쓸기 | ← |
| 일시정지 | – | P |

## 구성

- 스테이지 1~5: 점프·이단 점프·슬라이드
- 스테이지 6~10: 날아오는 송판 추가 (발차기로 격파)
- 스테이지 1~10: 흰띠 → 노란띠 → 주황띠 → 초록띠 → 파란띠 → 보라띠 → 밤띠 → 빨간띠 → 품띠 → 검은띠
- 스테이지 11~20: 검은띠 실전 · 숨은 함정 '끈끈이 바닥' (밟으면 실패, 걸리면 드러남)
- 스테이지 21~30: + 함정 '벼락' (숨은 구역에서 2단 점프하면 실패)
- 스테이지 31~40: + 함정 '철판' (송판처럼 날아오지만 차면 실패, 점프·슬라이드로 피하기)
- 스테이지 41~50: + 함정 '빙판' (빙판 위에서 점프하면 미끄러져 실패)
- 스테이지 51~60: + 함정 '낙하물' (떨어지는 화분, 뒤로 피하기로만 회피)
- 스테이지 61~70: + 함정 '비둘기 떼' (그냥 달려서 지나가기, 점프하면 실패)
- 스테이지 71~80: + 함정 '배달 오토바이' (앞에서 마주 옴. 짐이 낮으면 1단, 높으면 2단 점프)
- 스테이지 81~90: + 함정 '사범님 차렷!' (1초 동안 아무것도 누르면 안 됨)
- 70·80·90 심사 스테이지: 가짜 결승선
- 스테이지 91~100: 정전 (송이 주변만 보임)
- 100스테이지 클리어: 금메달 엔딩
- 목숨 1개, 실패 시 해당 스테이지부터 재도전, 스테이지별 배치 고정

## 테스트 모드

주소 끝에 `#test`를 붙이면 스테이지 선택과 무적 모드가 나옵니다.

## 앱으로 설치 (PWA)

- **안드로이드 (크롬)**: 게임 화면 아래 **앱 설치** 버튼, 또는 크롬 메뉴 → **앱 설치 / 홈 화면에 추가**
- **아이폰 (사파리)**: 공유 버튼 → **홈 화면에 추가**
- 설치하면 주소창 없이 전체화면 가로 모드로 실행되고, 한 번 연 뒤에는 인터넷 없이도 플레이됩니다.

## 파일 구성

```
index.html             게임 본체
manifest.webmanifest   앱 이름·아이콘·화면 설정
sw.js                  오프라인 캐시
icons/                 앱 아이콘 (192, 512, maskable, apple-touch, favicon)
```

`index.html`을 고친 뒤 올릴 때는 `sw.js` 맨 위의 `VERSION` 값을 올려주면(예: songi-v2) 설치된 앱도 바로 새 버전으로 바뀝니다.

## 실행

`index.html` 하나로 동작합니다. 브라우저로 열거나 GitHub Pages로 배포하세요.
